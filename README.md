# 澄墨笔记

澄墨笔记是一个面向学习、阅读和知识整理的离线优先 Markdown 笔记网站。它将笔记编辑器、沉浸式阅读器、文本标注和自由绘图放在同一工作区中，让一篇笔记可以从记录、阅读到批注持续演化。

项目提供两种使用方式：直接部署的静态网站，以及可继续开发的 React 源码。

> 设计说明：本项目在资料库、笔记列表、阅读标注和标注管理等交互上，参考了 [Zotero](https://www.zotero.org/) 的信息组织与阅读批注体验，尤其是“资料管理 + 阅读器 + 标注回顾”的工作流。澄墨笔记是独立的个人项目，与 Zotero 官方、其开发团队及其社区没有隶属或合作关系；项目不包含 Zotero 的代码或数据。

## 在线访问

GitHub Pages 从 `master` 分支的 `docs/` 目录发布站点。启用 Pages 后，可在仓库的 **Settings -> Pages** 查看实际访问地址。

## 核心功能

### 笔记与资料库

- 用分类组织笔记；支持新建、重命名和删除空分类。
- 在当前分类中创建、搜索、选择和删除笔记。
- 笔记列表与资料库可独立展开、收起；侧栏展开按钮支持拖动定位。
- 最近阅读自动记录最近打开的笔记，最多保留 5 条。
- 阅读会话会自动恢复，重新打开页面后尽量回到上次阅读的位置与笔记。

### Markdown 阅读与编辑

- 支持 Markdown 编辑、标题层级、标签和笔记归类。
- 使用 KaTeX 渲染行内及块级数学公式。
- 自动生成正文目录，并可从目录跳转到对应章节。
- 显示阅读进度、当前分类和当前笔记标题。
- 提供暖米色、豆沙绿、浅灰色三种阅读纸张主题。

### 文本标注

- 选中文本后可创建高亮或下划线标注，并选择颜色。
- 标注可添加评论和标签，支持修改颜色、切换标注类型和删除。
- 支持点击标注查看详情，以及长按打开标注管理菜单。
- 标注抽屉提供搜索、颜色筛选、标签浏览与按笔记回顾。
- 标注会基于文本片段及上下文重新定位，尽量在笔记内容调整后保持可用。

### 绘图与笔迹

- 在阅读页直接绘制自由笔迹，支持颜色、粗细和橡皮擦。
- 可选择笔迹、移动笔迹、删除选中笔迹，以及隐藏或显示全部笔迹。
- 绘图数据按笔记保存，避免不同笔记的笔迹互相影响。

### 数据与备份

- 默认离线保存，笔记内容不会主动上传到服务器。
- LocalStorage 用于快速启动缓存；IndexedDB 用于更可靠地持久化笔记、标注和笔迹。
- 可导出完整 JSON 备份，也可导入备份并合并不重复的数据。
- 删除笔记时会一并清理其关联的文本标注、绘图笔迹和最近阅读记录。

## 推荐使用流程

1. 在“笔记分类”中选择或新建一个分类。
2. 新建笔记，在编辑模式中写入 Markdown、公式和标签。
3. 切换到阅读模式，通过目录浏览章节。
4. 选中重点文本，添加高亮、下划线、评论或标签；需要手写内容时启用绘图。
5. 在标注抽屉中筛选、检索和回顾全部标注。
6. 定期使用“导出备份”保存 JSON 文件，以防浏览器数据被清除。

## 本地运行

### 直接查看发布版本

需要 Python 3。在 Windows 上双击 `Start-Chengmo.bat`，或在项目根目录运行：

```powershell
./start_chengmo.ps1
```

脚本会启动本地静态服务，并打开：

```text
http://127.0.0.1:8080/index.html
```

### 开发源码

需要 Node.js 和 pnpm：

```bash
pnpm install
pnpm dev
```

构建可发布的静态版本：

```bash
pnpm build:portable
```

构建结果位于 `outputs/澄墨笔记网站/`。发布前请同步该目录到 `docs/`，两个目录应保持一致；GitHub Pages 使用 `docs/` 目录。

## 项目结构

```text
src/                         React 与 TypeScript 源码
outputs/澄墨笔记网站/         可直接本地运行的静态网站
docs/                        GitHub Pages 发布目录
tools/                       构建、资源外置与持久化辅助脚本
serve_chengmo.py             8080 端口的静态服务
start_chengmo.ps1            Windows 本地启动脚本
Start-Chengmo.bat            Windows 双击启动入口
```

## 数据与隐私

数据默认只保存在当前浏览器的站点存储中。清除浏览器缓存、站点数据或使用隐私模式，都可能导致本地笔记不可恢复。请在重要修改后导出备份文件，并妥善保存。

导入备份会合并笔记、分类、标注、笔迹和最近阅读记录中不重复的项目，而不是直接覆盖当前数据。
